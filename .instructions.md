# ShadowMen Backend Architecture

## Project Overview
This is a Node.js/Express backend for the ShadowMen e-commerce platform, connected to Neon PostgreSQL.

## Key Technologies
- **Runtime:** Node.js with TypeScript
- **Framework:** Express.js
- **Database:** PostgreSQL (Neon)
- **Authentication:** JWT (JSON Web Tokens)
- **Password Hashing:** bcryptjs

## API Routes (39 endpoints across 7 route files)

### Authentication (`routes/auth.ts`)
- POST /api/auth/signup - Register user
- POST /api/auth/login - Authenticate user
- GET /api/auth/verify - Verify JWT token

### Products (`routes/products.ts`)
- GET /api/products - List all products with filters
- GET /api/products/:id - Get single product
- POST /api/products - Create product (merchant only)
- PUT /api/products/:id - Update product (merchant only)
- DELETE /api/products/:id - Delete product (merchant only)

### Orders (`routes/orders.ts`)
- GET /api/orders - Get user's orders
- GET /api/orders/:id - Get order details
- POST /api/orders - Create new order
- PATCH /api/orders/:id/status - Update order status

### Cart (`routes/cart.ts`)
- GET /api/cart - View cart items
- POST /api/cart/add - Add to cart
- PUT /api/cart/:id - Update cart item quantity
- DELETE /api/cart/:id - Remove from cart
- POST /api/cart/clear - Clear all cart items

### Wishlist (`routes/wishlist.ts`)
- GET /api/wishlist - View wishlist
- POST /api/wishlist/add - Add to wishlist
- DELETE /api/wishlist/:id - Remove from wishlist
- GET /api/wishlist/check/:product_id - Check if in wishlist

### Users (`routes/users.ts`)
- GET /api/users/profile - Get user profile
- PUT /api/users/profile - Update profile
- POST /api/users/change-password - Change password
- GET /api/users/:id - Get user by ID

### Merchant (`routes/merchant.ts`)
- GET /api/merchant/dashboard - Dashboard stats
- GET /api/merchant/products - Merchant's products
- GET /api/merchant/orders - Merchant's orders
- GET /api/merchant/orders/:id - Order details for merchant
- GET /api/merchant/analytics/products - Product analytics
- GET /api/merchant/reviews - Reviews on products

## Database Tables
1. `users` - User accounts (customer/merchant roles)
2. `products` - Product listings
3. `orders` - Order records
4. `order_items` - Items in orders
5. `cart_items` - Shopping cart items
6. `wishlist_items` - Wishlist entries
7. `reviews` - Product reviews
8. `messages` - User messaging

## When Working With This Backend:

1. **Adding new endpoints:** Create files in `src/routes/`, import in `src/index.ts`
2. **Database queries:** Use `query()` function from `src/db/connection.ts`
3. **Protected routes:** Apply `authMiddleware` and optionally `requireRole`
4. **Making queries:** Always use parameterized queries to prevent SQL injection
5. **Testing:** Start server with `npm run dev` and test with Postman/Thunder Client

## Integration with Frontend:
- Copy `api.config.ts` to frontend's `lib/` folder
- Set `NEXT_PUBLIC_API_URL` in frontend `.env.local`
- Use `apiCall()` helper for all API requests
- Store JWT tokens in localStorage and include in Authorization header

## Security Notes:
- Passwords are hashed with bcryptjs
- Tokens expire in 7 days
- Always use HTTPS in production
- Change JWT_SECRET for production
- Use parameterized queries for all database operations
