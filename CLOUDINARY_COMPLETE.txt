📱 NEW API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

POST /api/upload/image
  • Upload single image
  • Authentication: Bearer token required
  • Body: multipart/form-data with 'image' field
  • Response: { url, optimizedUrl, publicId, width, height }

POST /api/upload/images
  • Upload multiple images (max 5)
  • Authentication: Bearer token required
  • Body: multipart/form-data with 'images' field
  • Response: { images: [...], count }

DELETE /api/upload/:publicId
  • Delete image from Cloudinary
  • Authentication: Bearer token required
  • Response: { message: "Image deleted successfully" }

🎯 COMPLETE WORKFLOW
═════════════════════════════════════════════════════════════════════════════

1️⃣  User uploads image
    └─ File selected in React component

2️⃣  Frontend uploads to backend
    └─ POST /api/upload/image with image file

3️⃣  Backend validates image
    └─ Check type (JPEG, PNG, GIF, WebP)
    └─ Check size (max 10MB)

4️⃣  Cloudinary receives image
    └─ Stores in cloud
    └─ Returns URL & public ID

5️⃣  Backend responds to frontend
    └─ Returns Cloudinary URL

6️⃣  Frontend stores URL in database
    └─ POST /api/products with image_url

7️⃣  Product created with image
    └─ Image URL stored in Neon PostgreSQL

8️⃣  Display product
    └─ Load image from Cloudinary URL
